给定长度为奇数 nnn 的 111 到 nnn 的排列 aaa，要求找出一种长度不超过 5n2\dfrac{5n}{2}25n​ 的操作序列，使 $$a$$ 变为升序，或判断无解。操作如下：

  • 选择一个 x∈[1,n]x \in [1,n]x∈[1,n]，且 xxx 为奇数，将 a1a_1a1​ 到 axa_xax​ 翻转。

3≤n≤20213 \le n \le 20213≤n≤2021 且为奇数，1≤ai≤n1 \le a_i \le n1≤ai​≤n。

首先怎么判断无解，因为 xxx 是奇数，所以翻转操作不改变位置的奇偶性，所以有解的充要条件是 iii 和 aia_iai​ 的奇偶性都相同。

考虑将两个数绑到一起且倒着操作，比如 nnn 和 n−1n-1n−1 一起操作，这样相当与每对数要在五次操作内移动到最后的位置。

我们假设现在考虑的数位置为 xxx 和 yyy，xxx 要移到位置 mmm，操作 F(x)F(x)F(x) 表示前 xxx 的翻转操作，以下给出方案：

  1. x=1,y=2:F(m)x=1,y=2:F(m)x=1,y=2:F(m)

  2. y+1=y:F(x),→1.y + 1 = y:F(x), \rightarrow 1.y+1=y:F(x),→1.

  3. x+1=y:F(y+1), F(y+2−x),→1.x + 1 = y:F(y+1), \ F(y + 2 - x),\rightarrow 1.x+1=y:F(y+1), F(y+2−x),→1.

  4. x+1<y:F(x),F(y−1)→2.x + 1 < y:F(x),F(y - 1)\rightarrow 2.x+1<y:F(x),F(y−1)→2.

  5. y+1<x:F(x),F(x−y)→2.y + 1 < x:F(x),F(x - y)\rightarrow 2.y+1<x:F(x),F(x−y)→2.
