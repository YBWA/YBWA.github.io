前置芝士

动态开点线段树

一般我们写线段树都是在刚开始调用一个 build 函数建立出所有节点。但实际上有很多节点并没有保存信息，这些节点是多余的。所以就有的动态开点线段树，只有在用到时才建立这个节点，这种思想节省了很多空间，节点与节点之间的灵活性也更高，为线段树合并和主席树等算法提供了基础。我们简单了解一下动态开点线段树的代码实现。

线段树节点不同于普通线段树，需要存储左右孩子的位置。

权值线段树

我们的线段树合并，99% 的情况合并的是权值线段树。 —— 某同机房巨佬

权值线段树类似于权值树状数组，是在值域上建立的的线段树，维护值的信息，如出现次数等。

其实和正常线段树没啥区别，就是因为维护的东西比较特殊就被拎出来了 Qwq。

权值线段树应该挺简单的，我们提一下就过吧。

线段树合并

顾名思义，合并两个线段树。一般用来维护与深度相关的信息、离线处理一些问题。

假设现在我们有两棵线段树 xxx 和 yyy ，我们考虑怎么合并，当然两棵线段树维护的区间显然要相等。

  • 如果 xxx 或 yyy 是空的（因为是动态开点），直接返回不空的那个；
  • 如果到达边界，即 xxx 和 yyy 维护的区间只有一个元素，直接合并维护的信息；
  • 否则递归合并 xxx 、 yyy 的左子树和右子树，用两个子树向上更新出合并后的节点。

考虑这样合并的复杂度是多少，显然是 Θ(节点数)\Theta \left( 节点数\right)Θ(节点数)，一般就是 Θ(nlog⁡n)\Theta(n \log n)Θ(nlogn) 了。

一些题目

[USACO17JAN]Promotion Counting P

link

给定一棵树 nnn 个节点、以 111 为根的树，树上每个点有权值 pip_ipi​。

求以每个点为根的子树内权值大于它的节点个数。

1≤n≤1051 \le n \le 10^51≤n≤105，1≤pi≤1091 \le p_i \le 10^91≤pi​≤109

线段树合并裸题，码个板子练练手。离散化后对于每个点建立权值线段树，维护每个值出现的次数，dfs\tt{dfs}dfs 将所有子节点线段树合并到父节点上，对于 pip_ipi​ 在线段树上查询 [pi+1,n]\left[p_i + 1 ,n\right][pi​+1,n] 区间和即可。

刚开始每个节点的线段树中只插入一个值，因此线段树上只有 log⁡n\log nlogn 个节点；合并操作中不会新建节点，因此总空间复杂度就是 Θ(nlog⁡n)\Theta(n \log n)Θ(nlogn)，每个节点会进行 Θ(log⁡n)\Theta(\log n)Θ(logn) 的合并，所以时间复杂度也是 Θ(nlog⁡n)\Theta(n \log n)Θ(nlogn)。

[POI2011]ROT-Tree Rotations

link

给定一棵 nnn 个叶子节点的二叉树，其中每个点要么没有子树，要么有两棵子树，叶子节点有权值 xxx。

你可以任意交换一个节点的左右子树，使得先序遍历得到的叶子节点权值的排列逆序对最少。

1≤n≤2×1051 \le n \le 2 \times 10 ^ 51≤n≤2×105，0≤x≤n0 \le x \le n0≤x≤n。

考虑到先序遍历是先父亲再左右子树，因此子树交换并不影响外部的逆序对。同样使用权值线段树加线段树合并，dfs\tt{dfs}dfs 考虑一个节点，我们计算出交换与不交换的两种贡献，取最小的即可，我们可以在合并线段树时计算两个节点之间的逆序对个数。

假设现在要合并 xxx 和 yyy，不交换就是 tr[tr[x].rs].sum * tr[tr[y].ls].sum，交换就是 tr[tr[x].ls].sum * tr[tr[y].rs].sum，接着在合并左右子树时处理剩下的逆序对。

这样说可能比较难理解，举个栗子：

假设现在左右子树 xxx、yyy 的排列分别为 1 2 3 3、1 1 2 3。

不交换有 888 个逆序对：2,1 2,1 3,1 3,1 3,2 3,1 3,1 3,2 ；

交换有 333 个：2,1 3,1 3,2；

建出两棵线段树：

节点内的红字这个节点的 sum\tt{sum}sum 值，即这个节点维护区间的值的数量。

刚开始两棵子树都在 [1,3]\tt{[1,3]}[1,3]；

  • 用 xxx 的 [3,3]\tt{[3,3]}[3,3] 区间乘以 yyy 的 [1,2]\tt{[1,2]}[1,2]，2×3=62 \times 3 = 62×3=6，代表不交换的逆序对 3,1 3,1 3,2 3,1 3,1 3,2 ；
  • 用 xxx 的 [1,2]\tt{[1,2]}[1,2] 区间乘以 yyy 的 [3,3]\tt{[3,3]}[3,3]，2×1=22 \times 1 = 22×1=2，代表交换的逆序对 3,1 3,2；

但是这样还有一些逆序对没找全啊？所以要在接下来 xxx、yyy 的左右子树合并时继续计算。

合并 xxx 、yyy 的左子树 [1,2]\tt{[1,2]}[1,2]：

  • 用 xxx 的 [2,2]\tt{[2,2]}[2,2] 区间乘以 yyy 的 [1,1]\tt{[1,1]}[1,1]，1×2=21 \times 2 = 21×2=2，代表不交换的逆序对 2,1 2,1 ；
  • 用 xxx 的 [1,1]\tt{[1,1]}[1,1] 区间乘以 yyy 的 [2,2]\tt{[2,2]}[2,2]，1×1=11 \times 1 = 11×1=1，代表交换的逆序对 2,1；

合并 xxx 、yyy 的左子树 [3,3]\tt{[3,3]}[3,3]，一个点显然没有逆序对，不用计算。

这样不交换有 6+2=86+2=86+2=8 个逆序对，交换有 2+1=32+1=32+1=3 个逆序对。这就对了嘛。

这道题同样需要 long long，另外因为是 nnn 个叶子节点不是 nnn 个节点，数组要开大一点。

CF208E Blood Cousins

link

给定一片 nnn 个点的森林，森林中的树都有根。

mmm 次询问，每次询问一个点 xxx 与多少个点有相同的 KKK 级祖先。

1≤n≤1051 \le n \le 10^51≤n≤105，1≤m≤1051 \le m \le 10^51≤m≤105

离线做法，首先用倍增对于每个询问求出 xxx 的 KKK 级祖先，用 vector\tt{vector}vector 或链表把询问挂在祖先上，问题转换成求一个点有多少个 KKK 级儿子的问题。

对每个节点，以深度为下标建立权值线段树，进行 dfs\tt{dfs}dfs。若 dfs\tt{dfs}dfs 到一个节点 xxx，在线段树插入当前点的深度并与子节点的线段树合并。然后遍历所有询问，对于询问这个点有多少个 KKK 级儿子，在线段树中查询深度为 depx+Kdep_x + Kdepx​+K 的节点有多少个即可。别忘了答案要减一。

时间复杂度 Θ(nlog⁡n)\Theta(n \log n)Θ(nlogn)。
