斜率优化入门

通过一道简单的例题入门斜率优化 Qwq。

任务安排2

给定 nnn 个有 TiT_iTi​、CiC_iCi​ 两属性的机器和 SSS，将其分为若干段，第 jjj 个段 [l,r]​[l, r]​[l,r]​ 的费用为

(sCr−sCl−1)×(S×j+sTr)(sC_r - sC_{l - 1})\times(S \times j + sT_r) (sCr​−sCl−1​)×(S×j+sTr​)

sCisC_isCi​，sTisT_isTi​ 为前缀和数组，求最小费用。

1≤N≤3×105,  1≤S, Ti, Ci≤5121 \le N \le 3 \times 10^5, \ \ 1 \le S, \ T_i , \ C_i \le 5121≤N≤3×105,  1≤S, Ti​, Ci​≤512

推dp

以下的 C​C​C​，T​T​T​ 数组皆为前缀和处理后的数组。

设 Fi,jF_{i,j}Fi,j​ 表示前 iii 个机器分 jjj 段的最小费用，枚举最后一段的开头 kkk，易得转移：

Fi,j=min⁡1≤k<i(Fk,j−1+(Ci−Ck)×(S×j+Ti))F_{i,j}=\min_{1\le k < i}(F_{k,j-1} + (C_i - C_{k})\times(S \times j + T_i)) Fi,j​=1≤k<imin​(Fk,j−1​+(Ci​−Ck​)×(S×j+Ti​))

最暴力的方程。将段产生的费用分出来，每次计算当前这一段对后面的费用影响，即费用提前计算思想，可以优化掉第二维：

Fi=min⁡1≤j<i(Fj+(Ci−Cj)×Ti+(Cn−Cj)×S)F_i= \min_{1\le j < i}(F_j + (C_i-C_j)\times T_i + (C_n-C_j) \times S) Fi​=1≤j<imin​(Fj​+(Ci​−Cj​)×Ti​+(Cn​−Cj​)×S)

这样可以达到 Θ(n2)\Theta(n^2)Θ(n2) 的时间复杂度，对于本题的数据范围显然是不可行的，我们要对它进行优化废话。

对于这个式子，发现它同时包含了与 iii、jjj 相关的项（Cj×TiC_j \times T_iCj​×Ti​），比较不好处理，这时就要用到斜率优化了。

斜率优化

将上面的式子进一步展开：

Fi=min⁡1≤j<i(Fj+Ci×Ti−Cj×Ti+Cn×S−Cj×S)F_i=\min_{1\le j < i}(F_j + C_i\times T_i - C_j \times T_i + C_n \times S - C_j \times S) Fi​=1≤j<imin​(Fj​+Ci​×Ti​−Cj​×Ti​+Cn​×S−Cj​×S)

与 jjj 无关的可以提到左边：

Fi−Ci×Ti−Cn×S=min⁡1≤j<i(Fj−Cj×Ti−Cj×S)F_i -C_i \times T_i - C_n \times S = \min_{1 \le j < i}(F_j - C_j \times T_i - C_j \times S) Fi​−Ci​×Ti​−Cn​×S=1≤j<imin​(Fj​−Cj​×Ti​−Cj​×S)

即

Fi−Ci×Ti−Cn×S=min⁡1≤j<i(Fj−(Ti+S)×Cj)F_i - C_i \times T_i - C_n \times S = \min_{1 \le j < i}(F_j - (T_i + S)\times C_j) Fi​−Ci​×Ti​−Cn​×S=1≤j<imin​(Fj​−(Ti​+S)×Cj​)

类比一次函数 y=kx+by=kx + by=kx+b，变为 b=y−kxb = y - kxb=y−kx，那么就可以这样设：

Bj=Fi−Ci×Ti−Cn×SYj=FjKj=Ti+SXj=CjB_j = F_i - C_i \times T_i - C_n \times S \\ Y_j = F_j \\ K_j = T_i + S \\ X_j = C_j Bj​=Fi​−Ci​×Ti​−Cn​×SYj​=Fj​Kj​=Ti​+SXj​=Cj​

这就是一条以 Ti+ST_i + STi​+S 为斜率，Fi−Ci×Ti−Cn×SF_i - C_i \times T_i - C_n \times SFi​−Ci​×Ti​−Cn​×S 为截距的直线（截距就是一次函数的 bbb）。

Ci×TiC_i \times T_iCi​×Ti​ 和 Cn×SC_n \times SCn​×S 都是已知量，不会改变，所以求 FiF_iFi​ 的最小值就是找到一个合适的 jjj，使截距最小化。

显然这样的决策点 (Cj,Fj)(C_j,F_j)(Cj​,Fj​) 一定在下凸壳上（下凸壳：相邻两点连线斜率单调上升的若干个点），这个很容易从图形上直观理解，就不证明了。

这就是一个下凸壳。那哪个点才是我们想要的决策点呢？显然，当直线与凸壳相交时交点左边的斜率都小于直线斜率，右边都大于直线斜率，看图就很好理解：

这样我们只要在凸壳上找到这样的一个分界点即可。怎么找呢？不难发现斜率 Ti+ST_i + STi​+S 是单调递增的，所以在凸壳上这个分界点一定是逐渐右移的，像这样：
